# Asad Raza — Portfolio

Vite + React 19 + Tailwind v4 + Motion + Lenis. Deployed on Vercel.

```bash
npm install
npm run dev
```

- All content lives in `src/data.js` — edit that, not the components.
- Résumé served at `public/Asad_Raza_Resume.pdf` (copy of `my_all_resumes/Asad_Raza_SRN.pdf`).
- Sections: `src/hero.jsx` (nav, hero, phone mock), `src/sections.jsx` (rest), motion helpers in `src/fx.jsx`.
